# Описание SPA на TypeScript

    Функционирующее в браузере одностраничное приложение, позволяющее вести учет заявок - 
добавлять новые, изменять и удалять существующие.
    
    В приложении реализован подход FSD для удобной работы с текущим и новым функционалом, 
в перспективе - масштабированием.
    
    В приложении реализована авторизация пользователя через Firebase, защищающая информацию на страницах от
несанкционированного доступа.
    
    Для ввода информации в формы используются React Hook Forms с валидацией.

    Для хранения информации используется localStorage браузера в связке с Redux Persist. Redux Persist настроен
на один store и два slice.
